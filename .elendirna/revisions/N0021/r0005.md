## Delta

## 다음 버전 포함 결정: CLI/MCP 첨부파일 MVP (2026-04-24)

사용자와 논의한 결과, 첨부파일 기능은 다음 버전에 올릴 구현 후보로 확정한다.

핵심 판단:
- stdio 기반 MCP에서는 별도 바이너리 파일 전송 primitive를 먼저 설계하기보다, CLI와 같은 로컬 path import 모델을 사용하는 것이 적합하다.
- 즉 `elf entry attach <ID> <FILE_PATH>`와 MCP `entry_attach(id, path)`는 같은 코어 함수를 공유하는 구조가 좋다.
- HTTP/chunk upload/resume/auth는 현재 우선순위가 아니며, 원격 전송 요구가 실제로 커질 때 별도 계층으로 다룬다.

다음 버전 범위:
- CLI `entry attach/detach/assets`
- MCP `entry_attach/entry_detach/entry_assets`
- `.elendirna/assets/` 복사 및 `manifest.sources` 갱신
- sync event 기록
- path resolution/source path/copied key/size/mime 등 응답 메타데이터 포함

비범위:
- HTTP upload session
- chunk upload
- resume/retry
- remote object storage
- sha256/CAS/full validate는 후속 단계 후보
