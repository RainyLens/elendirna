## Delta

## 확정: asset key 충돌은 자동 affix + collision flag + warning (2026-04-24)

첨부파일 MVP의 asset key 충돌 정책을 확정한다.

정책:
- 동일 asset key가 이미 있으면 실패시키지 않는다.
- 서버가 `_2`, `_3` 같은 affix 숫자를 붙여 고유 key를 생성한다.
- 최종 저장된 key/file name을 API result에 반환한다.
- 기계 처리를 위해 `collision: true`를 반환한다.
- 사람/AI가 놓치지 않도록 `warnings[]`에도 충돌 및 최종 저장명을 포함한다.

예시 응답:
```json
{
  "ok": true,
  "entry_id": "N0021",
  "asset_key": "N0021_diagram_2.png",
  "stored_filename": "N0021_diagram_2.png",
  "source_path": "D:\\work\\diagram.png",
  "original_name": "diagram.png",
  "collision": true,
  "size": 12345,
  "mime": "image/png",
  "warnings": [
    "Asset key already existed; stored as N0021_diagram_2.png."
  ]
}
```

판단:
충돌은 오류가 아니라 자동 해결된 주의사항이다. 따라서 작업은 성공으로 유지하고, 구조화 신호(`collision`)와 설명 신호(`warnings`)를 함께 제공한다.
