## 현상 및 원인 분석 (2026-04-16)

### 현상
- `cargo run -- --version`, `cargo run -- --help` 등 모든 CLI 실행 시 패닉 발생
- 에러 메시지: `Command elf: command name 'help' is duplicated`

### 원인
- `src/main.rs`의 `Commands` enum에서 `Help(cli::help::HelpArgs)` 서브커맨드를 수동으로 정의함
- `clap` v4는 기본적으로 `help` 서브커맨드를 자동으로 생성하므로 중복 충돌 발생
- `Cli` 구조체에 `disable_help_subcommand = true` 속성을 추가하거나 서브커맨드 이름을 변경해야 해결 가능

### 영향
- 현재 버전(v0.4.2) 바이너리의 모든 기능 실행 불가 (build는 성공하나 runtime panic)
- AI용 JSON 가이드(`elf guide` 등)가 정상 작동하지 않음
