## Delta

## 세부 동작 설계 확정 (2026-04-16)

### 1. 쓰기의 암묵적 local 우선
vault 파라미터 없는 모든 tool(읽기+쓰기)의 vault 해석 순서:
1. 명시적 vault 파라미터 → 그 값 사용
2. local 등록됨 → local vault 사용 (암묵적)
3. local 미등록 → primary vault 사용 (기존 동작)

### 2. session_start 재호출 시 충돌 감지 + 확인 흐름
이미 local이 등록된 상태에서 다른 경로로 session_start 호출 시:
- ok: false, conflict: true 반환
- current_local / requested_local 포함
- confirm=true 파라미터로 재호출해야 전환 완료
→ 에이전트가 반드시 사용자에게 확인을 구하는 구조

### 3. bundle 링크 해석 범위
vault 파라미터로 지정된 vault 내에서만 링크 entry를 탐색.
해당 vault에 linked entry 없으면 에러 + validate 호출 권장.
cross-vault 링크 추적 없음.

### 4. session_start 응답에 resolved 경로 포함
find_vault_root(CWD) 경로로 자동 탐색된 경우에도
실제 resolve된 절대경로를 local_vault 필드로 반환.
