## 핵심 갭: 모든 tool 응답에 resolved vault 출처 누락

N0038/N0039는 "어느 vault에 쓸지 지정하는 수단"을 다루지만,
"실제로 어느 vault에서 읽고/썼는지 응답으로 확인하는 수단"이 없다.

### 오늘 발생한 사고 경로 (2026-04-16)
1. MCP session이 global vault를 primary로 시작
2. AI가 entry_list 호출 → 응답에 vault 필드 없음
3. AI는 로컬 vault 결과로 착각하여 잘못된 분류 수행
4. entry_new, revision_add 호출 → 전역 vault에 기록됨
5. 응답에 vault 필드 없어서 AI가 오염 사실을 인지 불가

### 필요한 수정
모든 MCP tool 응답에 resolved_vault 필드 추가:
- 읽기 tool (entry_list, entry_show, bundle, query): 어느 vault에서 읽었는지
- 쓰기 tool (entry_new, revision_add, sync_record): 어느 vault에 기록했는지

### 보안 관점
vault는 격리 경계(security boundary)임.
응답에 출처가 없으면 AI가 격리 위반을 인지할 수 없고,
사용자도 사후에 추적이 어려움.
