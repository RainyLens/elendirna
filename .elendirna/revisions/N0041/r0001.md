→ see N0040 (vault 출처 누락 버그와 같은 세션에서 발견)

## 증상

MCP tool `sync_record` 호출 시 `entries` 파라미터를 배열로 전달하면 역직렬화 오류 발생:
```
failed to deserialize parameters: invalid type: string "[\"N0024\", \"N0040\"]", expected a sequence
```

MCP 클라이언트가 배열을 JSON 문자열로 직렬화하여 전달하거나,
서버 측 파라미터 스키마가 배열 타입을 올바르게 선언하지 않은 것으로 추정.

## 임시 대응

CLI로 우회: `elf sync record --entries "N0024,N0040"` (쉼표 구분 문자열)

## 확인 필요

- SyncRecordParams의 `entries: Option<Vec<String>>` 스키마 선언이 올바른지
- rmcp의 배열 파라미터 역직렬화 처리 방식
