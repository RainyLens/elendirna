## Claude Memory vs Vault 비교 실험 (2026-04-16)

두 시스템이 같은 사실을 다른 각도에서 기록한다는 가설을 실제로 비교해 봄.

**Claude Memory (AI가 관찰한 것):**
- 코딩 컨벤션, 프로젝트 진행 과정, 수정 이력
- "어떻게 작업하는가"에 대한 프로세스 중심

**Vault (본인이 기록한 것):**
- 설계 사상, 결정 이유, UX 통찰
- "무엇을 생각하는가"에 대한 내용과 판단 중심

**결론:**
- Vault ∩ Memory = 서로 중요하다고 인식한 공통 분모
- Vault - Memory = 본인은 중요하다고 여기지만 AI가 아직 패턴으로 인식 못한 것
- Memory - Vault = AI 눈에는 보이지만 본인은 의식하지 못한 행동/성향

후자가 특히 가치 있음. 자신이 인식하지 못하는 의사결정 패턴을 AI가 먼저 발견하는 케이스.
