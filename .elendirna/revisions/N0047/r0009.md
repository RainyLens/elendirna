## Delta

## 정정: MCP 혼동의 주체 명확화 (2026-04-30)

[Change]
앞선 r0008의 "MCP 개념 오해가 정리되었다"는 표현을 더 정확히 보정한다. 이 대화에서 MCP의 stdio/local transport 및 tool protocol 성격은 Elendirna 제작자(pluvia)가 이미 이해하고 설명한 내용이며, 혼동은 ELF 원작자(Eli) 쪽에서 "MCP server"를 원격 서버/자연어 기반 skill에 가깝게 이해한 데서 발생했다.

[Impact]
제품적 함의는 유지된다. 다만 대상 사용자상은 "Elendirna 제작자도 혼동했다"가 아니라, ELF/Base-Delta 배경을 가진 사용자도 MCP라는 이름 때문에 원격 서버나 자연어 프롬프트 계층으로 오해할 수 있다는 점이다. 따라서 설명 문구는 `stdio 로컬 도구 프로토콜`, `CLI 함수의 MCP tool 래핑`, `규칙을 기억시키는 대신 규칙이 적용되는 API 제공`을 더 명시해야 한다.
