## Delta

## v0.5 결정 상태 정리: 큰 미결은 undo 하나만 남음 (2026-04-24)

사용자와 재검토한 결과, v0.5의 큰 스코프 결정은 대부분 닫혔다.

확정:
1. MCP multi-vault 완성
2. 첨부파일 CLI/MCP MVP
3. sync_record entries 역직렬화 수정
   - 공식 입력은 JSON array
   - 호환 입력은 string/comma-separated/stringified JSON array까지 느슨하게 수용
   - sync_record는 source of truth가 아니라 handoff hint이므로 fail-soft 정책 적용

큰 미결:
4. Single-step Undo
   - 구현 여부/정책 모두 추가 논의 필요
   - hard delete vs soft delete, 전역 최신 write vs entry별 기준, sync 기록 방식, 불변성 원칙과의 관계를 먼저 정해야 함

보조 미결:
- 첨부파일 attach/detach에서 sync event 기록 실패를 핵심 조작 실패로 볼지, warning으로 둘지 같은 트랜잭션 경계는 구현 직전 결정 필요
- duplicate candidates/FTS/similar 기능은 후속 후보이며 v0.5 범위 밖

결론:
v0.5의 제품적 스코프에서 남은 큰 논제는 undo 하나로 봐도 된다. 나머지는 구현 세부 정책 또는 후속 버전 후보로 분리된다.
