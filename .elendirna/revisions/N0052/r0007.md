## Delta

## v0.5 첨부파일 정책 확정: 충돌 warning 포함 (2026-04-24)

v0.5 첨부파일 MVP에서 asset key 충돌 처리는 다음으로 확정한다.

- 충돌은 실패가 아니다.
- 서버가 affix 숫자로 자동 해결한다.
- API result에는 최종 `asset_key`/`stored_filename`을 반환한다.
- `collision: true`를 포함한다.
- `warnings[]`에 충돌 사실과 최종 저장명을 포함한다.

이 정책은 테스트/클라이언트에는 구조화 필드로, 사람/AI에게는 warning 메시지로 같은 사실을 전달한다. 따라서 자동 처리는 안정적이고, 사용자는 파일명이 바뀐 사실을 놓치지 않는다.
