# Instruction: Phase 2 - Attachments MVP (CLI/MCP)

본 지시는 v0.5 마일스톤의 두 번째 단계인 '첨부파일 MVP 구현'을 목표로 합니다. 코어 로직(`src/vault/ops.rs`)은 이미 구현되어 있으므로, 이를 CLI와 MCP 도구에 연결하십시오.

## 요구사항

### 1. CLI 명령어 추가 (`src/cli/entry.rs`)
다음 명령어를 추가하고 `src/vault/ops.rs`의 함수들을 호출하십시오.
- `elf entry attach <ID> <FILE_PATH> [--copy-name <NAME>] [--json]`
- `elf entry detach <ID> <ASSET_KEY> [--json]`
- `elf entry assets <ID> [--json]`
- 각 명령어는 작업 결과를 사람용(pretty) 또는 JSON 형식으로 출력해야 합니다.
- 파일 경로 처리는 현재 작업 디렉토리(cwd) 기준으로 절대 경로로 변환하여 `ops`에 전달하십시오.

### 2. MCP 도구 추가 (`src/mcp/mod.rs`)
다음 도구들을 추가하십시오.
- `entry_attach(id, path, copy_name?, vault?)`
- `entry_detach(id, asset_key, vault?)`
- `entry_assets(id, vault?)`
- 모든 도구는 Phase 1에서 구현된 `resolve_tool_vault`를 사용하여 볼트를 해결해야 합니다.
- 응답에 `vault`, `vault_kind`, `asset_key`, `collision` 등의 메타데이터를 포함하십시오.

### 3. 검증
- `cargo check` 및 `cargo test`를 실행하여 기존 기능에 영향이 없는지 확인하십시오.
- 가능하다면 간단한 통합 테스트를 `tests/` 폴더에 추가하는 것을 권장합니다.

## 주의사항
- `sync.jsonl` 이벤트 기록은 `ops` 함수 내에서 이미 처리되지만, CLI/MCP에서 추가적인 경고(warning)나 상태 메시지를 적절히 출력하십시오.
- `src/cli/mod.rs`에서 새 서브커맨드를 등록하는 것을 잊지 마십시오.
- 작업 완료 후 N0052(PLAN v0.5)의 체크리스트를 업데이트하십시오.
