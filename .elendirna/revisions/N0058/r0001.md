## Delta

# Release Summary: v0.5 "Multi-vault & Attachments"

v0.5 마일스톤 작업이 완료되었습니다. 이번 버전의 핵심은 MCP 서버의 활용성 극대화와 데이터 무결성이 보장된 첨부파일 시스템 도입입니다.

## 주요 변화

### 1. MCP Multi-vault 지원 완성
- 단일 MCP 세션에서 `local`, `global` 및 사용자 정의 별칭 볼트를 자유롭게 전환하며 작업할 수 있습니다.
- `resolve_tool_vault` 로직을 통해 경로 보안 검증(`ensure_vault_root`)이 강화되었습니다.

### 2. 첨부파일(Attachments) MVP 구현
- **CLI:** `elf entry attach`, `detach`, `assets` 명령어가 추가되었습니다.
- **MCP:** 에이전트가 직접 파일을 첨부하고 관리할 수 있는 도구가 추가되었습니다.
- **안정성:** 파일명 충돌 방지(`affix`), Path Traversal 방지, 원자적 쓰기 보호 로직이 적용되었습니다.

### 3. sync_record 입력 유연화
- `entries` 파라미터가 JSON 배열뿐만 아니라 쉼표 구분 문자열 등 다양한 형식을 지원하여 에이전트의 실수에 강인해졌습니다.

### 4. 코드 품질 및 검증
- Codex CLI의 정밀 검수를 통해 보안 취약점을 사전에 차단했습니다.
*   총 76개의 테스트 케이스를 통과했습니다.

## 향후 과제 (v0.6+)
- **Single-step Undo:** 작업 실수 시 `sync.jsonl` 기반으로 마지막 변경을 되돌리는 기능 검토.
- **Asset Cleanup:** `detach`된 후 어떤 엔트리에서도 참조되지 않는 파일을 정리하는 `elf gc` 기능.
