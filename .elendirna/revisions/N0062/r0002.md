### 타입 정의 (src/vault/mod.rs)

```rust
#[derive(Debug, Clone, PartialEq, Eq, Serialize)]
pub enum VaultOrigin {
    ExplicitPath,
    ExplicitGlobal,
    Alias(String),
    EnvVar,
    CwdSearch,
    FallbackGlobal,
}

#[derive(Debug, Clone, Serialize)]
pub struct VaultResolution {
    pub path: PathBuf,   // canonicalized, 서버 시작 시 고정
    pub origin: VaultOrigin,
}

#[derive(Debug, Clone, PartialEq, Eq)]
pub enum WritePolicy {
    Allowed,
    WarnRequiresConfirm(String),  // warning 메시지 포함
    // v0.6에서 Block 추가 예정
}

impl VaultResolution {
    pub fn write_policy(&self) -> WritePolicy { ... } // origin 기반 파생
}
```

- `is_read_only: bool` 제거 → `WritePolicy`로 대체 (origin 기반 파생, warning 메시지 포함)
- `Alias(String)`은 Eq 가능, Copy 불필요
- Serialize: 진단/응답 포함용, Deserialize 불필요
