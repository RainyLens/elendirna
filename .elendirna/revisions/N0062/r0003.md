## 범위 재평가: N0040 사고 원인은 이미 해결됨 (2026-04-27)

[Change] v0.5.1 범위를 대폭 축소.

N0040의 오염 사고는 session_start가 vault 출처 정보를 반환하지 않던 시절에 발생했다. 현재 session_start는 vault_root / vault_kind / hint를 명시적으로 반환하므로 근본 원인은 이미 해결된 상태.

따라서 Round 2에서 도출한 VaultOrigin / VaultResolution / WritePolicy 타입 프레임워크는 현시점 기준으로 복잡도 증가에 가깝다. 근거가 약해졌다.

### 재평가된 v0.5.1 실질 범위

| 항목 | 판단 |
|---|---|
| `"local"` alias 수정 | **포함** — 설계-구현 불일치, correctness 문제 |
| `vault_resolution` 문자열 필드 | 선택적 polish |
| `fallback: true + warning` | session_start hint가 이미 커버 |
| `WritePolicy + confirm` 프레임워크 | **제외** — 근거 약함, v0.6 이후 재검토 |

[Impact] v0.5.1 핵심은 `resolve_named_vault("local")` 수정 한 건. 나머지는 필요 시 별도 판단.
