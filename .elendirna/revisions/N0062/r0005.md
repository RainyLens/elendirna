## confirm 의도 정정 + N0046 연결 (2026-04-27)

[Change] write guard 조건 수정 및 undo와의 관계 명시.

### confirm 조건 정정

이전 안의 `origin == FallbackGlobal && !confirm`은 의도와 다름.
원래 의도: **local이 아닌 모든 쓰기에 경고** — FallbackGlobal뿐 아니라 explicit global, alias 등 비로컬 대상 전체.

```rust
// 수정된 인라인 체크
if vault_kind != "local" && !confirm {
    return warning response
}
```

VaultResolution 기반으로 표현하면:
```rust
if !matches!(resolution.origin, VaultOrigin::CwdSearch | VaultOrigin::ExplicitPath)
    && !is_session_local
    && !confirm {
    return warning
}
```

### N0046 undo와의 관계

→ see N0046 (Single-step Undo Mechanism)

confirm은 **쓰기 전** 안전장치, undo는 **쓴 후** 교정 수단. 같은 write-safety 설계의 두 층.

- confirm/warning: 비로컬 쓰기 의도 재확인 → 실수 방지
- undo: 실수가 발생했을 때 직전 1건 취소 → 피해 최소화

두 기능이 함께 있을 때 "accidental write"에 대한 완전한 대응이 갖춰짐.
N0046의 구현 보류 상태는 별개로, 설계 의도 상 이 두 기능은 같은 문제 공간에서 파생됨.
