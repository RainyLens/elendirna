## Delta

## 개선: 사전 컨텍스트 주입 단계 추가 (2026-04-27)

[Change] 협업 흐름에 Step 0 추가 — sub-agent 호출 전 관련 entry를 미리 주입.

### 문제
session_start는 orientation(방향 잡기)만 제공. 작업 주제에 대해 "이미 결정된 것"을 agent들이 모른 채 제안하면 기존 맥락을 재발명함. 오늘 WritePolicy/confirm 사례가 대표적.

### 개선된 협업 흐름

```
Step 0 (Claude): query/bundle로 관련 entry 탐색 → 핵심 결정/제약 요약 추출
Step 1 (Gemini): 초안 제안 [요약 포함해서 프롬프트에 주입]
Step 2 (Codex):  검토 [동일 요약 포함]
Step 3 (Claude): 종합
```

### 주입 내용 기준
- 같은 태그/주제의 기존 proposal/decision entry
- 관련 설계 원칙 (non-compulsive 등)
- 이미 기각된 아이디어 ("이건 한번 검토했는데 X 이유로 보류")

[Impact] AI들이 "이미 있어"를 모르고 재발명하는 루프를 줄일 수 있음. 사람의 개입 빈도 감소.
