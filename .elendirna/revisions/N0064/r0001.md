## 개요 (2026-04-27)

→ see N0049 (publish: private→public 변환, 결이 다름)
→ see N0038 (multi-vault 격리 정책)

"분재(bonsai)" 은유: vault 전체가 자라는 지식 나무라면, 특정 가지(entry/subtree)를 잘라 다른 vault에 이식하는 기능.

### 동기

- N0063 같은 협업 가이드를 local vault에서 global vault로 이식하고 싶다
- 프로젝트 vault에서 키운 지식을 global vault로 승격하거나, 반대로 global 원칙을 local에 복사하고 싶다
- publish(N0049)는 public artifact 변환이지만, 이건 **private vault 간 이동/복제**

### 핵심 개념

**Transplant (이식)**
- entry + revision chain을 다른 vault로 이동 또는 복사
- linked entry 포함 여부 선택 가능 (depth 파라미터)
- 이식 후 원본 vault의 entry는 archived 또는 그대로 유지

**Bonsai (분재/가지치기)**
- 이식 전 revision chain을 정리: 전체 chain vs 요약된 snapshot만
- 민감한 revision은 제외하고 핵심만 추출해서 이식
- 일종의 "증류(distillation)" — 긴 토론 과정 없이 결론만 옮기기

### 예상 인터페이스

```bash
# entry 하나를 global vault로 이식 (revision chain 포함)
elf transplant N0063 --to global

# subtree(linked entries 포함)를 다른 프로젝트 vault로 복사
elf transplant N0063 --to ../other-project --depth 2

# bonsai: revision을 요약 snapshot으로 압축 후 이식
elf transplant N0063 --to global --bonsai

# MCP tool
entry_transplant(id="N0063", target_vault="global", bonsai=true)
```

### publish(N0049)와의 차이

| | publish | transplant |
|---|---|---|
| 대상 | private → public artifact | vault → 다른 vault (모두 private 가능) |
| 형태 | 재작성 (AI 가공) | 구조 보존 (원본 이식) |
| revision | 미포함 (결과물만) | 포함 가능 (chain 선택) |
| 목적 | 공개 전 검토 | 지식 재배치/공유 |

### work_context와의 연결
