## Delta

## 파라미터 설계: bundle과 동일한 범위 (2026-04-27)

[Change] transplant 파라미터가 bundle과 같은 축으로 설계됨을 명시.

bundle: 수집 → 반환
transplant: 수집 → 다른 vault에 기록

수집 로직이 동일하므로 파라미터도 자연스럽게 같은 축:

```bash
elf transplant <id>
  --to <vault>          # 대상 vault (필수)
  --depth <n>           # linked entry 탐색 깊이 (bundle의 depth와 동일)
  --since <N####@r####> # 특정 revision 이후만 이식 (bundle의 since와 동일)
  --bonsai              # revision chain을 snapshot으로 압축 후 이식
```

구현 관점에서도 bundle 로직을 재사용하고 출력 대신 target vault write로 교체하는 구조.
