## bundle과의 근본적 차이: 출력 형태 (2026-04-27)

[Change] bundle과 transplant의 결정적 차이 명시.

| | bundle | transplant |
|---|---|---|
| 출력 형태 | 내용을 이어붙인 텍스트 | 파일 구조 그대로 (또는 압축) |
| 소비자 | AI (읽기용) | vault (쓰기용) |
| 구조 보존 | 없음 (렌더링) | 있음 (manifest.toml, note.md, revisions/ 등) |

파라미터 축은 같지만 내부 구현은 다름:
- bundle: 파일 읽기 → 텍스트 합산 → 반환
- transplant: 파일 읽기 → 디렉터리 복사 또는 압축 → 대상 vault에 기록

bonsai 옵션은 이 맥락에서 "복사 전 revision을 snapshot으로 압축" — 파일 수를 줄이는 역할.
