## 시나리오 추가: 주제 분리 (2026-04-27)

[Change] transplant의 세 번째 시나리오 추가.

연구 주제가 너무 커졌을 때 별개 vault로 분리해서 독립 관리.

git monorepo에서 특정 패키지를 별도 repo로 추출하는 것과 같은 맥락.

- 처음엔 main vault 안의 몇 개 entry로 시작
- 점점 커져서 subtree가 독립 vault로 관리할 만한 규모가 됨
- 관련 entry + revision chain + linked entries를 통째로 새 vault로 이식
- 이후 main vault에는 "→ moved to vault:xxx" 표시만 남기거나 archived

### 세 가지 시나리오 정리

| 시나리오 | 대상 | 목적 |
|---|---|---|
| 주제 분리 | 나 → 내 새 vault | 규모 커진 subtree 독립 관리 |
| 지인 공유 | 나 → 타인의 vault | 아이디어 번들 전달 |
| 공개 배포 | 나 → 불특정 다수 | → N0049 publish로 커버 |
