## Cross-vault 참조 문법

`[alias/]N####` 형식. `[]` 내부 생략 가능 — 생략 시 현재 vault, 명시 시 alias/namespace로 resolve.

예시:
- `→ see N0063` — 현재 vault (하위 호환 유지)
- `→ see 2026/N0063` — alias "2026"으로 등록된 vault
- `→ see prev-year/N0063` — named alias

**설계 결론:** alias = vault namespace. 별도 시스템 불필요. `register_vault_alias`에 연간 vault 등록 컨벤션 + note.md 파서가 `alias/N####` 패턴 인식하면 완성.

## 연간 Vault Rotation 패턴

장기적으로 연간 새 vault 생성은 자연스러운 bonsai 주기. alias로 `2026`, `prev-year` 등 등록하면 cross-vault 링크와 자연스럽게 통합됨. bonsai와 공통 전제조건: cross-vault 링크 문법.

[Impact] cross-vault 링크 문법이 alias 확장임을 확정. 연간 rotation이 현실적 시나리오로 편입.
