## Delta

## migration 시 note seed 부재 (2026-04-28)

[Change] 실제 migration 시도(→ see N0067)에서 발견된 인터페이스 공백.

기존 markdown 파일을 vault로 이관할 때 현재 흐름:
1. `entry_new(title, tags)` → note.md = 빈 shell, manifest만 생성
2. `revision_add(id, delta=원본 본문)` → 본문이 r0001 delta로 들어감

결과: note.md는 영영 빈 채로 남고, 본문은 revision chain에서만 조회 가능. "delta"라는 이름과 어긋남 — r0001은 delta가 아니라 **seed**.

[Impact]
transplant/migration의 전제 조건으로 seed 인터페이스 필요:
- `entry_new(body=...)` 옵션 추가, 또는
- `entry_import(markdown=..., title?, tags?)` 별도 도구

import 후에야 후속 `revision_add`가 진짜 delta로 의미를 가짐. transplant 구현 시 이 인터페이스가 먼저 정의되어야 함.

→ see N0067 (다른 머신에서 docs/knowledge 이관 중 함께 드러난 vault 해결 이슈)
