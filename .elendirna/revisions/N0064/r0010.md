## 메타포 정착: transplant·bonsai·seeding·inception·pruning (Discord 04-25/04-30 흡수, 2026-05-07)

Discord 토론에서 vault transplant 개념을 둘러싼 메타포 군집이 정착됨. r0001 첫 제안에 r0008 안전 임계 use case가 더해졌고, 여기 메타포 어휘를 명문화.

### 04-25 (Pluvia)
- **transplant**: vault를 다른 환경으로 옮길 수 있다. 종 / 토양 비유
- **bonsai**: 큐레이션된 topic vault를 분재처럼 키워 공유 가능. 가지치기·정형화로 외부 공유 형태 유지

### 04-30 (Pluvia / Eli)
- **seeding (Pluvia)**: 새 vault 또는 새 entry를 시작할 때 기존 entry에서 씨앗을 가져옴. blank slate가 아닌 prior context 기반 출발
- **inception (Eli)**: seeding보다 더 정확. 단순 시작이 아니라 "이전 기록에서 가지를 친다". `→ see N####` 링크 + baseline이 inception의 기술적 표현
- **pruning (Eli)**: foundation model의 unwanted output branch를 줄이는 것. "연결 삭제"가 아니라 "원치 않는 분기 약화". vault inception은 모델이 출력 후보를 좁히는 데 기여

### 메타포 매트릭스

| 메타포 | 작용 | 기술적 표현 |
|---|---|---|
| transplant | vault 단위 이식 | bundle export → 새 vault에 import |
| bonsai | topic vault 큐레이션·공유 | tag 필터 / 외부 publish |
| seeding | 새 entry 시드 | `entry_new(baseline=N####)` + `→ see` |
| inception | 가지 치기로 분기 | baseline + revision delta |
| pruning | 모델 출력 분기 약화 | tool description + 기존 entry context로 모델 답변 좁히기 |
