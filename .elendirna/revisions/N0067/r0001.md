### 증상
- MCP `entry_new(vault="local")` per-call 파라미터를 줘도 글로벌 vault에 N0078로 생성됨
- alias 'local' 자체가 인식 안 됨

- elf CLI는 같은 cwd에서 정상 인식 → MCP 서버 측 vault 해결 경로 문제

### 가설
- **CC Desktop MCP 세션 라이프사이클**: 재시작이 깨끗하지 않아 이전 세션 vault 상태 잔존 → per-call 파라미터를 덮어쓰지 못함
- **cwd 기반 자동 등록 부재**: MCP 서버가 실행 시점 cwd의 local vault를 자동 등록하지 않음 (명시적 등록 필요)
- per-call vault override 로직 자체 결함 가능성 — 명세상으로는 호출당 적용되어야 함

### Workaround (확인됨)
elf CLI 직접 호출로 대체 — cwd 기반 vault 인식 정상.

### Stance

- 단, **per-call vault override가 명세대로 작동하는지**는 별도 조사 필요 — 명세 위반이면 버그
