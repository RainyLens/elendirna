## 리스크 / 판단

### 'local' 시맨틱 변경 영향
- 현재: `'local'` = launch_resolution path (cwd 탐색 결과 그대로)
- 변경 후: 같은 path지만 home 매칭 시 origin이 다름 → write 가드 작동
- read는 영향 없음. write만 confirm 필요해짐
- 사용자에게 유리: silent global write 차단

### 호환성
- 응답 JSON에 새 필드 추가만, 제거 X — backward compatible
- 기존 클라이언트는 `escalated_write` 무시 가능
- 기존 origin string은 유지 ("cwd_search"). 새 "cwd_search_home" 추가만

### CC Desktop 사용자 영향
- N0067 보고 시나리오: home에 글로벌 vault, process cwd=home → 첫 entry_new 시도에서 confirm 요구 받게 됨 → 사용자가 진정한 'local' 의도면 명시 path 사용
- silent global 오염 차단
