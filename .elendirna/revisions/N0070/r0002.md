### Phase A 정밀화

기존 PLAN: "find_local_vault_root 결과가 home과 same path면 CwdSearchHome"

→ **수정**: find_local_vault_root 자체를 건드리지 않음. 결과 path를 home과 비교하는 wrap만 추가:

```rust
// src/cli/serve.rs (또는 동일 모듈)
let resolved = find_local_vault_root(&cwd)?;
let canon = resolved.canonicalize().unwrap_or(resolved.clone());
let home_canon = home_vault_root().ok().and_then(|h| h.canonicalize().ok());
let origin = if Some(&canon) == home_canon.as_ref() {
    VaultOrigin::CwdSearchHome
} else {
    VaultOrigin::CwdSearch
};
```

장점: find_local_vault_root 자체 시맨틱 보존. 새 비교 단계만 추가
주의: symlink/junction은 canonicalize로 흡수. Windows %USERPROFILE%/Linux $HOME 모두 home_vault_root 추상화로 해결됨
