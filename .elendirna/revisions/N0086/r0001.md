## Current default

`bundle(id, depth=1, since=None)` — depth=1 즉 linked entry 전문 포함.

## Options considered

**(a) Conservative default + escalation hint**
- default `depth=0` (revisions만)
- 응답에 "linked entry N개, depth=1 호출 시 ~X bytes 예상" hint
- 단점: 매 호출 2-step, 정보 누락 risk

**(b) Auto-bound by estimated_bytes 임계**
- estimated_bytes 임계 초과 시 자동 truncation
- 단점: 비결정적, predictability ↓

**(c) Implicit since-based bounding**
- depth=1 유지, since를 "최근 N revisions" 자동 적용
- 단점: implicit cutoff로 stale revision 누락 risk

**(d) Default 안 건드리고 응답 hint만 추가** ← 잠정 추천
- "이 entry size 큼, 후속 호출 시 since=... 또는 depth=0 권장" next-action signal
- 정책/default 변경 없음, predictable
- 추가 비용: 응답 JSON에 hint field 하나
- cost 자각은 agent-side로 위임 (induce, not gate — N0025 원칙 부합)

## Tentative direction
