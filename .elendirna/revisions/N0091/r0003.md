## N0086 구체값 결정 — (a) Conservative default 채택 (2026-05-20)

사용자 결정: **(a) depth=0 default + 응답 hint**.

### Phase G 구현 spec

- `bundle(id)` default → `depth=0` (revisions만, linked entry 미포함)
- 명시 호출 `bundle(id, depth=1)` 또는 `bundle(id, depth=2+)`는 기존 동작 그대로
- `since` default 변경 없음 (`None`)

### 응답 hint (cost_hint 필드)

bundle 응답에 `cost_hint: Option<String>` 추가:
- inject 조건: `depth=0` default 결과인데 linked entry가 존재할 때
- 예시: `"linked 3개 entry 추가 가능 (depth=1 호출 시 ~64KB 예상). bundle(id, depth=1)로 escalate"`
- estimated_bytes 추정은 linked entry의 manifest+note 길이 합산

### description 변경

`mcp__elendirna__bundle` description에 cost shape 한 줄 추가:
- "depth=0 default (revisions만). linked entry 필요 시 depth=1 명시"

### session_start `bundle_policy` hint 정합

기존 hint 그대로 살아있음 — "처음 보거나 확실하지 않은 핵심 entry는 bundle(id, depth=1)". default depth=0과 자연 정합.

### backward compat

bundle 응답 contract 추가만 (cost_hint optional). depth default 변경은 behavior break — v0.6.0 changelog 명시 필요.
