# Pilot question staging

`questions.draft.jsonl` is a five-question wiring set for the frozen real vault
snapshot. It remains outside the vault to avoid retrieval contamination.

The questions are not the 30-item blinded pilot and their lexical results are
not product evidence. Before a real pilot:

1. review every gold reference and claim;
2. replace copied vault vocabulary with natural paraphrases;
3. tune on no more than these five questions;
4. freeze all parameters;
5. author 25 additional questions that were never used during tuning.

If any question or its analysis is recorded in the vault, retire that question
from future evaluation rounds.
